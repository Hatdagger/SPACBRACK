# Art tests (not part of the game build)

- `samples/` — first art-direction sheet (flat style, rejected as too simple). `template.html` + fonts injected = `index.html`.
- `hero/` — high-effort code-drawn hero (back view, satin tour jacket, one 15-colour palette). Kept as the reference for the hero's look until sourced art arrives.
- `templates/` — exact-size asset templates for the pixel artist (16-px grid, safe areas, palette budgets). `make_templates.py` rebuilds `out/`. Full specs: "SPACBRACK Art Asset Guide" doc (https://claude.ai/artifact/2vrnw9dArsoMXGxxRg39vz).
